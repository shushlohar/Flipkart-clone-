# Flipkart-clone
This is a frontend website clone inspried by flipkart using by HTML , CSS , and Java script 

# Features 
A fully interactive Flipkart clone featuring dynamic search, filters, cart, checkout, and review systems that save directly in your browser without needing a backend.

# Technologies
HTML5 , CSS3 , Javascript 

# What I learn 
Frontend project structing , frontend code wirting semless , UI intraction
